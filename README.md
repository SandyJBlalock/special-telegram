# Special Telegram

For the 2026 Winter Wonderland hackaton.

**Make the group chat feel a little more special.**

Special Telegram is a hackathon project that helps Telegram groups celebrate people and moments together. Members can send a **Special**, a cheerful, customizable shout-out for a birthday, a milestone, a helpful teammate, or just because. The bot shares it in the group with a fun card-style message.

## What it does

- Create a Special for someone in the group.
- Pick a moment, add a message, and choose an emoji.
- Preview the Special before sharing it.
- Browse recent Specials in the chat.
- Use simple commands and buttons designed to be easy to try during a hackathon demo.

## Example

> 🎉 **A Special for Maya!**  
> Thanks for always making the team’s brainstorming sessions brighter.  
> — From Jordan

## Try it

1. Start a chat with the Special Telegram bot.
2. Send `/start` to see the available options.
3. Choose **Create a Special** and follow the prompts.
4. Select the group where you want to share it.

## Commands

| Command | What it does |
|---|---|
| `/start` | Get started and see the bot’s options |
| `/special` | Create a new Special |
| `/recent` | View recent Specials in the current chat |
| `/help` | See the command guide |

This is a **hackathon prototype**: a small demo of a more thoughtful group-chat experience. Features and behavior may change as the project develops.

2. Add the token to your local environment using the variable name expected by the project.
3. Install the project’s dependencies.

See the project’s setup files for exact commands and configuration. **Do not commit bot tokens or other credentials** to the repository.
